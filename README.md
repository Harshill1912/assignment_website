# NEXORA BIO — Engineering Biology for a Healthier Tomorrow

A premium, original biotechnology company landing page built for high-end research, precision medicine, and synthetic cell programming. Designed with a luxury scientific laboratory aesthetic, cinematic typography, Framer Motion scroll reveals, and high-performance interactive 2D Canvas visualizations.

---

## 🚀 Technology Stack

- **Framework**: React 18 with TypeScript & Vite
- **Styling**: Tailwind CSS with custom HSL design system tokens, glassmorphism utilities, and typography scaling
- **Animation System**: Framer Motion (layout animations, scroll triggers, modal drawers, hover micro-interactions)
- **Scientific Graphics Engine**: HTML5 2D Canvas API (interactive molecular network, rotatable DNA double helix, cell signaling arrays, and interactive telemetry inspector)
- **Icons**: Lucide React

---

## 🎨 Design & Animation Architecture

### Design Philosophy
- **Aesthetic**: Scientific Laboratory + Luxury Tech Brand + Cinematic Editorial website.
- **Palette**: Obsidian deep charcoal (`#06080C`), laboratory cyan (`#00F2FE`), emerald (`#10B981`), and subtle electric lime (`#A3E635`) accents on dark slate cards.
- **Typography**: Google Fonts — `Plus Jakarta Sans` for clean display/body copy and `JetBrains Mono` for scientific telemetry data.

### Animation System
- **Hero Stagger**: Page load typography entrance with interactive mouse-magnetics molecular canvas background.
- **Interactive Laboratory Explorer**: A 3-mode biophysical simulation engine (`Molecular Mesh`, `DNA Helix`, `Cellular Signal`) allowing users to adjust velocity fields, toggle modes, and inspect node telemetry.
- **Scroll Reveal**: Viewport-triggered section entrances with blur-to-sharp transitions, sticky glass navigation, and animated statistics counters.

---

## ⚡ Performance & Accessibility

- **60 FPS Canvas Rendering**: Optimized 2D Canvas rendering using requestAnimationFrame with automatic node count downscaling for mobile viewports.
- **Accessibility**: Full ARIA dialog semantics, keyboard navigation (`ESC` modal dismiss, focus trapping), semantic HTML5 hierarchy, and `prefers-reduced-motion` CSS & JS fallbacks.
- **Zero Heavy Dependencies**: Lightweight setup avoiding bloated WebGL bundles to maintain instant load times and high Lighthouse performance scores.

## 🛠️ Setup & Local Development Instructions

### Prerequisites
- Node.js (v18.x or v20.x recommended)
- npm or yarn

### Installation
```bash
npm install
```

### Development Server
Run the local dev server:
```bash
npm run dev
```

### Production Build & Linting
Validate TypeScript compilation and bundle production distribution:
```bash
npm run build
```

Preview production build locally:
```bash
npm run preview
```
